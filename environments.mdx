Most people using eReceipt only ever interact with the **production** environment — the live mobile app and the public website. This page documents the environments that exist and where each is accessed, in case a merchant or partner needs to reference them.

## Public surfaces

| Surface | URL |
| --- | --- |
| Marketing site | [https://myereceipt.com](https://myereceipt.com) |
| Documentation | [https://docs.myereceipt.com](https://docs.myereceipt.com) |
| iOS app | [App Store](https://apps.apple.com/app/id6587549323) |
| Android app | Google Play |

## Mobile app build variants

The eReceipt mobile app ships as three separate iOS bundle identifiers so internal and external testing never mix with production accounts. Each variant has its own Plaid OAuth redirect path.

| Variant | iOS bundle ID | Plaid OAuth path |
| --- | --- | --- |
| Production | `com.myereceipt.ereceipt` | `/plaid-oauth/prod` |
| Preview | `com.myereceipt.ereceipt.preview` | `/plaid-oauth/preview` |
| Development | `com.myereceipt.ereceipt.dev` | `/plaid-oauth/dev` |

All three variants use the same universal-link fallback page at [https://myereceipt.com/plaid-oauth/…](https://myereceipt.com/plaid-oauth/prod) so a linked card can complete OAuth even if the app is not installed.

<Note>
  Only the **production** variant is available in the App Store and Google Play. Preview and development builds are for the eReceipt engineering and QA teams.
</Note>
