By the end of this guide you'll have a live E-Receipt account, a working API key, and a digital receipt successfully delivered to a customer's email address. You'll make two API calls — one to create a customer and one to create and send a receipt — using nothing more than a terminal or your preferred HTTP client. Let's get started.

<Steps>
  <Step title="Create your account">
    Sign up for a free account at [app.e-receipt.com](https://app.e-receipt.com). Once you've verified your email and logged in, navigate to **Settings > API Keys** in the left-hand sidebar. This is where you'll generate and manage the credentials your application uses to authenticate with the E-Receipt API.
  </Step>
  <Step title="Get your API key">
    On the **API Keys** page, click **Create new key**, give it a descriptive name (for example, `my-first-integration`), and click **Generate**. Copy the key immediately — for security reasons it is only shown once. Store it somewhere safe, such as an environment variable or a secrets manager.

    E-Receipt issues two types of keys: `erecp_live_...` keys hit the production API, and `erecp_test_...` keys hit the sandbox at `https://sandbox.api.e-receipt.com/v1` — no real emails or SMS messages are sent in sandbox mode. Use a test key while following this guide.

    You'll use your key in the `Authorization` header of every API request:

    ```http
    Authorization: Bearer erecp_test_xxxxxxxxxxxx
    ```

    Your **Merchant ID** is also displayed on this page — keep it handy, as you'll need it when creating receipts.
  </Step>
  <Step title="Create a customer">
    Before you can send a receipt, you need a customer record. Call `POST /v1/customers` with the customer's name and email address. E-Receipt stores this contact so you can send them receipts in the future without re-entering their details.

    ```bash
    curl -X POST https://api.e-receipt.com/v1/customers \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Jane Smith",
        "email": "jane@example.com"
      }'
    ```

    The response includes a `customer_id` (for example, `cus_abc123`). Copy this value — you'll use it in the next step.
  </Step>
  <Step title="Create and send a receipt">
    Create a receipt by calling `POST /v1/receipts` with your merchant ID, the customer ID from the previous step, and the line items for the transaction. Then trigger delivery by calling `POST /v1/receipts/{id}/send`.

    **Create the receipt:**

    ```bash
    curl -X POST https://api.e-receipt.com/v1/receipts \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "merchant_id": "mer_xyz789",
        "customer_id": "cus_abc123",
        "currency": "USD",
        "items": [
          { "name": "Organic Coffee Blend", "qty": 2, "price": 12.99 },
          { "name": "Reusable Travel Mug", "qty": 1, "price": 24.95 }
        ],
        "total": 50.93
      }'
    ```

    The response includes a receipt `id` (for example, `rec_def456`). Use that ID to send the receipt:

    **Send the receipt:**

    ```bash
    curl -X POST https://api.e-receipt.com/v1/receipts/rec_def456/send \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    A `200 OK` response confirms that the receipt has been queued for delivery.
  </Step>
  <Step title="View the receipt">
    Within a few seconds, Jane receives an email at `jane@example.com` containing your branded receipt. The email includes a **View Receipt** button that opens a mobile-friendly receipt page hosted by E-Receipt. You can track delivery and open status in real time from the **Receipts** tab of your dashboard. If you set up webhooks, E-Receipt will also notify your server when the receipt status changes to `sent` and then `viewed`.
  </Step>
</Steps>

## Send a receipt — language examples

The code below shows the full receipt creation request in cURL, JavaScript, and Python. All three examples create the same receipt.

<CodeGroup>

```bash cURL
curl -X POST https://api.e-receipt.com/v1/receipts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "merchant_id": "mer_xyz789",
    "customer_id": "cus_abc123",
    "currency": "USD",
    "items": [
      { "name": "Organic Coffee Blend", "qty": 2, "price": 12.99 },
      { "name": "Reusable Travel Mug", "qty": 1, "price": 24.95 }
    ],
    "total": 50.93
  }'
```

```javascript JavaScript
const response = await fetch("https://api.e-receipt.com/v1/receipts", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    merchant_id: "mer_xyz789",
    customer_id: "cus_abc123",
    currency: "USD",
    items: [
      { name: "Organic Coffee Blend", qty: 2, price: 12.99 },
      { name: "Reusable Travel Mug", qty: 1, price: 24.95 },
    ],
    total: 50.93,
  }),
});

const receipt = await response.json();
console.log("Created receipt:", receipt.id);
```

```python Python
import requests

response = requests.post(
    "https://api.e-receipt.com/v1/receipts",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "merchant_id": "mer_xyz789",
        "customer_id": "cus_abc123",
        "currency": "USD",
        "items": [
            {"name": "Organic Coffee Blend", "qty": 2, "price": 12.99},
            {"name": "Reusable Travel Mug", "qty": 1, "price": 24.95},
        ],
        "total": 50.93,
    },
)

receipt = response.json()
print(f"Created receipt: {receipt['id']}")
```

</CodeGroup>
