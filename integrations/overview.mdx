## Integration approaches

E-Receipt offers three distinct ways to connect your systems, each suited to a different level of technical investment and customization need.

**1. Native integrations**

Native integrations are pre-built connectors that link E-Receipt directly to a supported platform — no code required. You authenticate once through an OAuth flow or API key, configure your preferences in the E-Receipt dashboard, and receipts begin flowing automatically. Native integrations are the fastest way to go live if your platform is on the supported list.

**2. Webhooks**

Webhooks let E-Receipt push real-time event notifications to a URL you control. When a receipt is sent, delivered, opened, or encounters an error, E-Receipt sends an HTTP POST to your endpoint with a structured JSON payload. Use webhooks to trigger downstream actions in your own systems — updating a CRM, logging to a data warehouse, or alerting your support team — without polling the API.

**3. REST API**

The E-Receipt REST API gives you full programmatic control over every resource in the platform: customers, receipts, templates, delivery channels, and more. Use the API when you need a custom integration that goes beyond what a native connector or webhook provides — for example, embedding receipt creation inside a proprietary order management system or a mobile app.

## Choosing the right approach

Use the table below to quickly identify the best fit for your situation.

| Scenario | Recommended approach |
|---|---|
| You use a supported POS or e-commerce platform | Native integration |
| You need receipts triggered by your own internal systems | REST API |
| You want to react to receipt events in real time (e.g., sync delivery status) | Webhooks |
| You use an unsupported or custom-built platform | REST API |
| You want both automated sending and event-driven sync | Native integration + Webhooks |

In practice, many businesses combine approaches: a native integration handles receipt creation at checkout while webhooks keep a CRM or analytics tool in sync with delivery and engagement events.

<Tip>
  Before connecting any live system, use the E-Receipt **sandbox environment** to send test receipts and verify your configuration end-to-end. Sandbox events are fully isolated from production data, so you can experiment freely without affecting real customers. Switch between environments using the toggle in the top-right corner of the dashboard.
</Tip>
