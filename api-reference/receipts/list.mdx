List and filter receipts across your entire account for reporting, auditing, or bulk operations. You can narrow results by customer, delivery status, or date range, and page through large result sets using the `page` and `per_page` parameters. Results are returned in reverse chronological order — most recently created first.

## Endpoint

```
GET https://api.e-receipt.com/v1/receipts
```

## Query parameters

<ParamField query="customer_id" type="string">
  Return only receipts belonging to this customer ID. Combine with `status` or date filters to narrow results further.
</ParamField>

<ParamField query="status" type="string">
  Filter receipts by their current status. Accepted values: `draft`, `queued`, `sent`, `delivered`, `viewed`, `failed`.
</ParamField>

<ParamField query="from" type="string">
  ISO 8601 date (e.g., `2025-01-01`). Return only receipts created on or after this date.
</ParamField>

<ParamField query="to" type="string">
  ISO 8601 date (e.g., `2025-03-31`). Return only receipts created on or before this date.
</ParamField>

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of receipts to return per page. Defaults to `20`. Maximum `100`.
</ParamField>

## Example request

<CodeGroup>

```bash cURL
curl "https://api.e-receipt.com/v1/receipts?customer_id=cus_9KJ2mXpLqR&status=delivered&from=2025-01-01&to=2025-03-31&page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  customer_id: "cus_9KJ2mXpLqR",
  status: "delivered",
  from: "2025-01-01",
  to: "2025-03-31",
  page: "1",
  per_page: "20",
});

const response = await fetch(
  `https://api.e-receipt.com/v1/receipts?${params}`,
  {
    headers: {
      "Authorization": "Bearer YOUR_API_KEY",
    },
  }
);

const { data, meta } = await response.json();
console.log(`${meta.total} receipts found across ${meta.total_pages} pages`);
```

</CodeGroup>

## Response fields

<ResponseField name="data" type="array">
  Array of receipt objects matching your query. Each object contains the full receipt representation. See [Retrieve a Receipt](/api-reference/receipts/retrieve) for a description of every receipt field.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the current result set.

  <Expandable title="meta object fields">
    <ResponseField name="total" type="integer">
      Total number of receipts matching your query across all pages.
    </ResponseField>

    <ResponseField name="page" type="integer">
      The current page number returned.
    </ResponseField>

    <ResponseField name="per_page" type="integer">
      Number of receipts returned per page.
    </ResponseField>

    <ResponseField name="total_pages" type="integer">
      Total number of pages available for the current query.
    </ResponseField>
  </Expandable>
</ResponseField>

<Tip>
  To retrieve all receipts for a specific date range across all customers, omit `customer_id` and use only the `from` and `to` parameters. This is useful for end-of-day or end-of-month reconciliation reports.
</Tip>
