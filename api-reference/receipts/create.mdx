Use this endpoint to create a new digital receipt for a customer. Every receipt starts in `draft` status after creation — it is not delivered until you explicitly call the [Send Receipt](/api-reference/receipts/send) endpoint. This two-step flow lets you review and adjust a receipt before it reaches the customer.

## Endpoint

```
POST https://api.e-receipt.com/v1/receipts
```

## Request body

<ParamField body="customer_id" type="string" required>
  The ID of the customer who will receive this receipt. You must create the customer profile first using [POST /v1/customers](/api-reference/customers/create).
</ParamField>

<ParamField body="currency" type="string" required>
  ISO 4217 three-letter currency code for all monetary amounts on this receipt (e.g., `"USD"`, `"EUR"`, `"GBP"`).
</ParamField>

<ParamField body="items" type="array" required>
  An array of line item objects that make up the receipt. At least one item is required.

  <Expandable title="Item object fields">
    <ParamField body="name" type="string" required>
      Display name of the product or service (e.g., `"Blue Widget"`).
    </ParamField>

    <ParamField body="quantity" type="number" required>
      Number of units purchased. Supports decimals for weight-based or fractional items.
    </ParamField>

    <ParamField body="unit_price" type="number" required>
      Price per single unit in the receipt's currency, as a decimal (e.g., `9.99`).
    </ParamField>

    <ParamField body="total" type="number" required>
      Total for this line item (`quantity × unit_price`). Pass this explicitly so your calculated value is preserved exactly.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="subtotal" type="number" required>
  Sum of all line item totals before tax and discount are applied.
</ParamField>

<ParamField body="tax" type="number">
  Tax amount to add to the subtotal, in the receipt's currency. Omit or pass `0` if no tax applies.
</ParamField>

<ParamField body="discount" type="number">
  Discount amount to subtract from the subtotal, in the receipt's currency. Omit or pass `0` if no discount applies.
</ParamField>

<ParamField body="total" type="number" required>
  Final amount charged to the customer (`subtotal + tax - discount`). This is the value displayed prominently on the receipt.
</ParamField>

<ParamField body="template_id" type="string">
  ID of the receipt template to use for rendering. If omitted, your account's default template is applied.
</ParamField>

<ParamField body="notes" type="string">
  A custom message displayed at the bottom of the receipt — useful for return policies, thank-you messages, or promotional copy. Maximum 500 characters.
</ParamField>

<ParamField body="metadata" type="object">
  A set of key-value pairs you can attach for your own internal reference (e.g., order IDs, store codes). Keys and values must be strings. Maximum 20 keys.
</ParamField>

<ParamField body="idempotency_key" type="string">
  A unique string (e.g., a UUID) that makes this request safely retryable. If you submit a request with the same `idempotency_key` within 24 hours, the API returns the original response instead of creating a duplicate receipt.
</ParamField>

## Example request

<CodeGroup>

```bash cURL
curl -X POST https://api.e-receipt.com/v1/receipts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customer_id": "cus_9KJ2mXpLqR",
    "currency": "USD",
    "items": [
      {
        "name": "Blue Widget",
        "quantity": 2,
        "unit_price": 14.99,
        "total": 29.98
      },
      {
        "name": "Shipping",
        "quantity": 1,
        "unit_price": 5.00,
        "total": 5.00
      }
    ],
    "subtotal": 34.98,
    "tax": 2.80,
    "discount": 5.00,
    "total": 32.78,
    "template_id": "tmpl_default_light",
    "notes": "Thank you for your purchase! Returns accepted within 30 days.",
    "metadata": {
      "order_id": "ORD-00421",
      "store_code": "NYC-01"
    },
    "idempotency_key": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }'
```

## Response fields

<ResponseField name="id" type="string">
  Unique identifier for the receipt, prefixed with `rec_`. Use this ID to retrieve, update, or send the receipt.
</ResponseField>

<ResponseField name="status" type="string">
  Current lifecycle status of the receipt. Newly created receipts always start as `"draft"`. Possible values: `draft`, `queued`, `sent`, `delivered`, `viewed`, `failed`.
</ResponseField>

<ResponseField name="customer_id" type="string">
  ID of the customer this receipt belongs to.
</ResponseField>

<ResponseField name="currency" type="string">
  ISO 4217 currency code used for all monetary values on this receipt.
</ResponseField>

<ResponseField name="items" type="array">
  Array of line item objects as submitted in the request body. Each item contains `name`, `quantity`, `unit_price`, and `total`.
</ResponseField>

<ResponseField name="subtotal" type="number">
  Sum of all line item totals before tax and discount.
</ResponseField>

<ResponseField name="tax" type="number">
  Tax amount applied to this receipt.
</ResponseField>

<ResponseField name="discount" type="number">
  Discount amount deducted from this receipt.
</ResponseField>

<ResponseField name="total" type="number">
  Final total charged to the customer.
</ResponseField>

<ResponseField name="template_id" type="string">
  ID of the template used to render this receipt.
</ResponseField>

<ResponseField name="notes" type="string">
  Custom message displayed at the bottom of the receipt.
</ResponseField>

<ResponseField name="metadata" type="object">
  Your key-value pairs attached to this receipt for internal reference.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when this receipt was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to this receipt.
</ResponseField>
